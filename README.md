Horror Game Prototype

A personal horror game prototype developed in Unity and C# in 2023.

This prototype was created to experiment with character movement, weapons, animations, enemy behavior, combat and atmosphere.

|Controls|
Key/Input|Action
______________________
W	       |Move forward
______________________
S	       |Move backward
______________________
Shift	   |Run
______________________
Mouse	   |Turn left / right
______________________
1	       |Equip Pipe
______________________
2	       |Equip Pistol
______________________
3	       |Equip AK-47
______________________
X	       |Holster weapon

Features:
Playable character
Three weapons: Pipe, Pistol and AK-47
Weapon animations
Running and movement animations
Enemy pursuit behavior
Enemy health system
Enemy animations
Blood effects when the enemy is shot
Ragdoll system
Nighttime test environment
Lighting designed for a horror atmosphere

About:

This was a personal game development experiment created in Unity in 2023.

The environment was intentionally kept simple, with the focus placed on testing gameplay mechanics, character movement, weapons, animations, enemy behavior and atmosphere.

The project is an early prototype and was not developed as a finished commercial game.
